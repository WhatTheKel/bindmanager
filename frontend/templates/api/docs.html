Authentication
ANY Authorization: Token bmt_…

Personal API tokens — the way to use the API with an Authentik or Okta account (no password needed), and the simplest option for scripts. Create one under your user menu → API tokens: it is shown once, acts as you with your role, expires after the period you choose, and can be revoked there at any time.

Example
curl {{ base_url }}v1/zones/ \
  -H "Authorization: Token bmt_…"

Errors: 401 for an unknown, revoked or expired token, or a deactivated account.

POST /api/token/

Obtain a JWT access token (15 min) and refresh token (1 day) using username and password. Local accounts only — SSO accounts have no password here; use a personal API token instead. Shares the login page's lockout: 10 failures per IP in 5 minutes → 429.

Request Body
FieldTypeRequiredDescription
usernamestringrequiredDjango username
passwordstringrequiredDjango password
Example
curl -X POST /api/token/ \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "secret"}'

# Response 200
{
  "access":  "eyJhbGci...",
  "refresh": "eyJhbGci..."
}
Usage
curl /api/v1/zones/ \
  -H "Authorization: Bearer eyJhbGci..."

POST /api/v1/zones/

Create a new zone. Assign nameservers via nameserver_ids.

Request Body
FieldTypeRequiredDescription
namestringrequiredFully-qualified domain name, e.g. example.com
zone_typestringrequiredforward or reverse
ip_versionintegeroptional4 or 6 (default 4)
refreshintegeroptionalSOA refresh interval in seconds
retryintegeroptionalSOA retry interval in seconds
expireintegeroptionalSOA expire time in seconds
minimum_ttlintegeroptionalSOA minimum TTL
default_ttlintegeroptionalDefault record TTL
nameserver_idsinteger[]optionalList of nameserver IDs to assign
Example
curl -X POST /api/v1/zones/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "example.com",
    "zone_type": "forward",
    "ip_version": 4,
    "nameserver_ids": [1, 2]
  }'

PATCH /api/v1/zones/{id}/  PUT

Partially or fully update a zone. Pass nameserver_ids to replace the assigned nameservers.

Example — change nameservers
curl -X PATCH /api/v1/zones/1/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"nameserver_ids": [1, 3]}'
DELETE /api/v1/zones/{id}/

Delete a zone and all its records. Returns 204 No Content.

POST /api/v1/records/

Create a DNS record. The parent zone is marked dirty and queued for BIND sync.

Request Body
FieldTypeRequiredDescription
zoneintegerrequiredZone ID
namestringrequiredRecord label. Use @ for the zone apex
record_typestringrequiredA, AAAA, CNAME, MX, TXT, NS, PTR, SRV, CAA…
valuestringrequiredRecord data (IP, hostname, TXT string, etc.)
ttlintegeroptionalTTL in seconds. Omit to inherit the zone default
priorityintegeroptionalRequired for MX and SRV records
is_activebooleanoptionalInclude in zone file (default true)
Example — add an A record
curl -X POST /api/v1/records/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "zone": 1,
    "name": "www",
    "record_type": "A",
    "value": "10.0.0.10",
    "ttl": 3600
  }'
Example — add an MX record
curl -X POST /api/v1/records/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "zone": 1,
    "name": "@",
    "record_type": "MX",
    "value": "mail.example.com.",
    "priority": 10
  }'
GET PATCH PUT DELETE /api/v1/records/{id}/

Retrieve, update, or delete a single record. PATCH accepts any subset of fields. DELETE returns 204 No Content.

Audit Log
GET /api/v1/audit/  Read-only

List audit log entries. Covers zone/record/nameserver changes, zone syncs, and user login events.

Query Parameters
ParameterTypeDescription
entity_typestringzone, record, nameserver, user
actionstringcreate, update, delete, sync, login, logout, login_fail
searchstringSearch in entity_type or detail text
orderingstringcreated_at or -created_at
Audit Entry Object
{
  "id":          42,
  "action":      "create",
  "entity_type": "record",
  "entity_id":   5,
  "detail":      "Added A \"www\" to example.com",
  "username":    "admin",
  "created_at":  "2026-07-01T08:00:00Z"
}
Example — recent login failures
curl "/api/v1/audit/?action=login_fail&ordering=-created_at" \
  -H "Authorization: Bearer <token>"
GET /api/v1/audit/{id}/

Retrieve a single audit log entry.
